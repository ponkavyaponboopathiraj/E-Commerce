# E-Commerce
🛒 DeluLu Cart – 🛠 Tech Stack

Frontend
---------
React.js
HTML5, CSS3, JavaScript
Axios
React Router

Backend
-------
Java
Spring Boot
Spring Security
JWT Authentication
REST APIs
Maven

Database
--------
MongoDB
PostgreSQL

Architecture
-------------
Microservices
Event-Driven Architecture
Saga Pattern
Kafka

Tools & Deployment
------------------
Git & GitHub
Postman
Docker
Kubernetes

Additional
--------------
SMTP / Gmail for Email Notifications


### 🚀 Prerequisites

* Java 17+
* Spring Boot
* React.js & Node.js
* MongoDB
* PostgreSQL
* Apache Kafka
* Maven
* Git & GitHub
* Postman
* Docker
* Basic knowledge of REST APIs, Microservices & JWT Authentication


## 💻 Development Commands

### Backend – Spring Boot
cd e-commerce_backend
.\mvnw.cmd spring-boot:run

### Frontend – React
cd e-commerce_Frontend
npm install
npm run dev

### MongoDB
mongosh

### Git
git status
git add .
git commit -m "your message"
git push

### API Testing
Postman → Test REST APIs

### Docker
docker build -t delulu-cart .
docker run -p 8080:8080 delulu-cart
